 QUICK CHECKLIST (Things You Need)

☐ Supabase Account (database)
  → Go to supabase.com and create free account
  → Create a new project
  → Copy Project URL and anon key
  
☐ OpenAI Account (AI engine)
  → Go to platform.openai.com
  → Create account and get API key
  → Copy the secret key
  
☐ Netlify Account (hosting)
  → Go to netlify.com
  → Sign up (you can use GitHub to sign in)
  
☐ GitHub Account (for code)
  → If you don't have one, create at github.com
  
═══════════════════════════════════════════════════════════════════════
 THE 4 THINGS TO DO
═══════════════════════════════════════════════════════════════════════

1. SET UP SUPABASE DATABASE
   - Create table: personal_data
   - Copy SQL from SETUP_GUIDE.md
   - Note: Project URL and anon key

2. SET UP OPENAI
   - Get API key from OpenAI
   - Note: The secret key

3. DEPLOY TO NETLIFY
   - Push code to GitHub
   - Connect GitHub repo to Netlify
   - Add these 4 environment variables:
     • SUPABASE_URL
     • SUPABASE_ANON_KEY
     • OPENAI_API_KEY
     • ADMIN_PASSWORD (make one up)

4. TRIGGER DEPLOY
   - Go to Netlify dashboard
   - Click "Trigger deploy"
   - Wait 5 minutes
   - Test the AI!
